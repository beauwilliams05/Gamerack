# Gamerack
Semester Project for CS 3311 Fall 2026

Steps
Run it locally
1. Put this folder in C:\xampp\htdocs
2. Start Apache and MySQL in XAMPP
3. Run database.sql in phpMyAdmin
4. Open http://localhost/gamerack/games.php
(for step 4, if you change the folder name from gamerack, then replace gamerack in the link with your folders name)
